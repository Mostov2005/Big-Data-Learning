## Лабораторная работа 3

### 1. Вывести название и столицу пяти наибольших стран по площади.
```
db.Страна.find(
  {}, 
  { _id: 0, Название: 1, Столица: 1 }
).sort({ Площадь: -1 }).limit(5)
```

### 2. Вывести список африканских стран, население которых не превышает 1 млн чел. (НЕТ ТАКИХ)
```
db.Страна.find(
  { Континент: "AF", Население: { $lte: 1000000 } },
  { _id: 0, Название: 1, Население: 1 }
)
```

### 3. Вывести список стран, население которых больше 5 млн чел., а площадь меньше 100 тыс. км², и они расположены не в Европе.

Превратить площадь в число:
```
db.Страна.updateMany(
  {},
  [{ $set: { Площадь: { $toDouble: "$Площадь" } } }]
)
```
Запрос:
```
db.Страна.find(
  {
    $and: [
      { Население: { $gt: 5000000 } },
      { Площадь: { $lt: 100000 } },
      { Континент: { $ne: "EU" } }
    ]
  },
  {
    _id: 0,
    Название: 1,
    Население: 1,
    Площадь: 1,
    Континент: 1
  }
).pretty()
```
### 4. Вывести список стран Северной и Южной Америки, население которых больше 20 млн чел., или стран Африки, у которых население больше 30 млн чел. (НЕТ ТАКИХ)
```
db.Страна.find(
  {
    $or: [
      { 
        $and: [
          { Континент: { $in: ["NA", "SA"] } },
          { Население: { $gt: 20000000 } }
        ]
      },
      { 
        $and: [
          { Континент: "AF" },
          { Население: { $gt: 30000000 } }
        ]
      }
    ]
  },
  {
    _id: 0,
    Название: 1,
    Континент: 1,
    Население: 1
  }
).pretty()
```

### 5. Вывести список стран, население которых составляет от 10 до 100 млн чел., а площадь не больше 500 тыс. км².
```
db.Страна.find(
  {
    $and: [
      { Население: { $gte: 10000000, $lte: 100000000 } },
      { Площадь: { $lte: 500000 } }
    ]
  },
  {
    _id: 0,
    Название: 1,
    Население: 1,
    Площадь: 1
  }
).pretty()
```

### 6. Вывести список стран Африки, Северной и Южной Америки.
#### Вариант 1 (через $or):
```
db.Страна.find(

    _id: 0,
```

```
  },

  }
).pretty()
```
